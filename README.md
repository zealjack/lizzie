# Lizzie Makanja — site

1. Create a free project at supabase.com
2. SQL Editor → paste & run `schema.sql`
3. Project Settings → API → copy URL + anon key into `config.js`
4. Right-click `index.html` → Open with Live Server
5. Go to Sign in → Sign up with Lizzie's email (confirm the email if asked)
6. Back in SQL Editor run the last (commented) line of `schema.sql` with her email → she is now the admin
7. Sign in → Writings page shows "New writing" form

Google sign-in (optional): Supabase → Authentication → Providers → Google, and add your
Live Server URL (e.g. http://127.0.0.1:5500/**) under Authentication → URL Configuration → Redirect URLs.
